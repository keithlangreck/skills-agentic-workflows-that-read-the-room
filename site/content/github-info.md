## Recent updates worth watching

- **Refreshed repository pull requests page is generally available.** A redesigned pull requests list makes it faster to scan, filter, and triage work across a repository.
  Source: https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available/
- **More ways to request and configure Copilot code reviews.** Teams can now tailor when and how Copilot reviews pull requests, making automated review easier to fit into existing workflows.
  Source: https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews/
- **Private saved views for repository issues are generally available**, along with a new "Relates to" issue relationship for tracking related work without extra labels.
  Source: https://github.blog/changelog/2026-09-25-personal-saved-views-for-repository-issues-and-more/
- **Workflow execution protections in GitHub Actions are generally available**, adding guardrails that help prevent unexpected or unauthorized workflow runs.
  Source: https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available/
- **When chat is the wrong UI**: a GitHub Blog look at how Copilot experiences go beyond chat, useful context for understanding where AI-assisted workflows are heading.
  Source: https://github.blog/ai-and-ml/github-copilot/when-chat-is-the-wrong-ui/
