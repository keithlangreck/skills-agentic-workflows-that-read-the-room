## Recent updates worth watching

- **Refreshed repository pull requests page (public preview)** — A redesigned repo-level PR list adds stronger filtering and a compact view mode, handy for repos with high PR volume. Source: https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview
- **Copilot code review can now approve pull requests** — With admin opt-in, Copilot can flag PRs as review-ready and formally approve them, a step toward AI-assisted review workflows. Source: https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests
- **Block pull requests with exposed secrets from merging** — Repository rulesets can automatically block merges when a PR introduces exposed secrets, guarding against accidental credential leaks. Source: https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging
- **Control GitHub Actions cache access with `cache-mode`** — A new setting lets teams enforce least-privilege access to the Actions cache at the workflow or job level, useful for securing CI pipelines. Source: https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode
- **Configure cost and quality in Copilot auto model selection** — Copilot's "auto" model selection now offers efficiency, balance, and intelligence tiers, letting developers tune the cost-vs-quality tradeoff for AI assistance. Source: https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection
