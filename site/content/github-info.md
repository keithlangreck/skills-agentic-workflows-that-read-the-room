## Recent updates worth watching

- **Refreshed repository Pull Requests page is now GA.** The redesigned Pull Requests tab makes it easier to find, filter, and act on PRs directly from the repository. Source: https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available
- **Copilot code review can now approve pull requests.** With admin opt-in, Copilot's review can submit an actual approval instead of only leaving advisory comments. Source: https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests
- **GitHub CLI supports media in issues, pull requests, and comments.** A new repeatable `--attach` flag in `gh` uploads a local image or video and inlines it, useful for scripted bug reports. Source: https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments
- **`cache-mode` gives finer control over GitHub Actions cache access.** The new setting enables least-privilege cache access at the workflow or job level, reducing cache poisoning risk in CI. Source: https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode
- **Rulesets can block pull requests that expose secrets.** Secret scanning can now be enforced as a hard merge gate instead of just a warning. Source: https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging
