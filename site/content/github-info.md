## Recent updates (September 2026)

- **Refreshed repository pull requests page is now GA** — The redesigned PR list page rolled out to all users, making it easier to discover and triage open pull requests. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available)
- **More ways to request and configure Copilot code reviews** — New personal settings, broader plan availability, and enterprise defaults make it simpler to standardize AI-assisted code review across a team. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews)
- **Node 20 is no longer available in GitHub Actions** — Node 20 runners have been dropped in favor of Node 24; maintainers of custom JavaScript Actions should update their action's runtime. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions)
- **Local sandboxing in the GitHub Copilot app** — A new per-project setting limits Copilot's file, network, and credential access on your machine, reducing risk when running agentic commands locally. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-23-local-sandboxing-in-the-github-copilot-app)
- **Rendering huge pull requests in the GitHub Copilot app** — Copilot's diff engine was rebuilt to open million-line pull requests with hundreds of comments, useful when reviewing very large changesets. Source: [GitHub Blog](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/)
