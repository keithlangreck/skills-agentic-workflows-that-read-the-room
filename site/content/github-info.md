## Recent updates (September 2026)

- **Refreshed repository pull requests page (public preview):** The repo-level Pull Requests tab now supports smarter AND/OR/nested filtering, a collapsible sidebar for quick filters like "Authored by me," a compact density view, and richer at-a-glance status info. Source: [github.blog/changelog](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview)
- **Control GitHub Actions cache access with `cache-mode`:** A new generally-available `cache-mode` setting scopes workflow/job cache access to `read`, `write`, `write-only`, or `none`, giving teams a least-privilege way to reduce cache-poisoning risk in CI pipelines. Source: [github.blog/changelog](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode)
- **Copilot code review can now approve pull requests:** Copilot code review provides a merge-readiness "approval assessment" and, if enabled, can submit an actual counted approval toward required-review rules. Source: [github.blog/changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests)
- **GitHub CLI: media in issues, pull requests, and comments:** `gh` (v2.99.0+) adds a repeatable `--attach` flag for `gh issue`/`gh pr` create/edit/comment commands, so you can inline images and videos into Markdown directly from the terminal. Source: [github.blog/changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments)
- **GitHub Copilot app for beginners: using the diff, terminal, and browser:** A beginner-friendly walkthrough of the Copilot app's three review panels (diff viewer, in-app terminal, and browser preview) for reviewing agent-made code changes before opening a PR. Source: [github.blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/)
